# Code of conduct

Be decent. Assume good faith. Argue about facts, not people.

This repository is a catalog, so most disagreements are about whether a claim is
accurate. Resolve those by citing a source. "I read the code and it does X, here
is the file and line" ends an argument; tone does not.

Unacceptable: harassment, personal attacks, doxxing, or sustained disruption.
Also unacceptable here specifically: knowingly submitting fabricated entries,
inflating your own project's description, or repeatedly submitting content you
have not read.

Maintainers will edit, remove or reject contributions that fall short, and may
block accounts that do so repeatedly.

Report a problem by opening an issue, or privately via the contact route in
SECURITY.md if it is sensitive.
