#
# >=2.0, not >=1.2: the SDK renamed FastMCP to MCPServer in 2.0, and server.py

# the import raises and the server never starts. Nothing in CI imports this
# module, so a wrong constraint here fails silently in a contributor's venv
# rather than in a build — which is the reason it is pinned by API, not by age.
